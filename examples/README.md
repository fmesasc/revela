# Ejemplos / Examples

Modelos `.glb` de prueba para arrastrar al editor:

- Astronauta (Google model-viewer):
  https://modelviewer.dev/shared-assets/models/Astronaut.glb
- Casco (Khronos glTF Sample Models):
  https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Models/main/2.0/DamagedHelmet/glTF-Binary/DamagedHelmet.glb

Descárgalos y úsalos con **＋ Modelo 3D**, o exporta desde Blender tu propio
`.glb` (File → Export → glTF 2.0).
