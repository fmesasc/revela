# Roadmap

Revela aims to cover the presentation features people expect from a modern
office suite, plus first-class 3D. This document tracks progress and priorities.
It is a living document; open an issue to propose or reprioritise items.

**Legend:** ✅ done · 🚧 in progress · ⬜ planned

## Editing
- ✅ Block-based canvas with drag, resize and keyboard nudging
- ✅ Alignment guides with snapping
- ✅ Undo / redo
- ✅ Right-click context menu
- ✅ Copy / cut / paste of objects
- ⬜ Multi-select and group operations
- ⬜ Grid and rulers, distribute / align across objects
- ⬜ Object rotation handle and grouping

## Content blocks
- ✅ Rich text (bold, italic, underline, strikethrough, colour, size, lists, alignment)
- ✅ Images
- ✅ Video
- ✅ Interactive 3D models (`.glb` / `.gltf`)
- ⬜ Shapes (rectangle, ellipse, arrow, line) with fill and stroke
- ⬜ Tables
- ✅ Code blocks (syntax highlighting)  ⬜ *(currently text only)*
- ⬜ Charts
- ⬜ Icons and emoji picker
- ⬜ SmartArt-style diagrams

## Layout & design
- ✅ Per-slide background colour
- ✅ reveal.js themes
- ✅ Slide size (16∶9, 4∶3)
- ⬜ Background images and gradients
- ⬜ Master slides / layouts
- ⬜ Colour palettes and text styles
- ⬜ Speaker notes

## Transitions & animation
- ✅ Per-slide transitions
- ✅ Per-object entrance animations
- ⬜ Emphasis and exit animations
- ⬜ Animation timeline and triggers
- ⬜ Morph-style transition between 3D models

## Media processing
- ✅ AI background removal for images
- ⬜ Basic image adjustments (crop, brightness, contrast, filters)
- ⬜ Video trimming

## Sections & navigation
- ✅ Sections
- ✅ Drag-and-drop slide reordering
- ⬜ Collapsible sections, move slides between sections by drag

## Templates
- ✅ Built-in templates
- ✅ Save current slide as a template
- ⬜ Full-deck themes / template gallery

## Import & export
- ✅ Export to self-contained HTML (reveal.js)
- ✅ Import from PowerPoint (`.pptx`) — text and images
- ⬜ Higher-fidelity `.pptx` import (fonts, colours, shapes)
- ⬜ Export to PDF
- ⬜ Export to `.pptx`

## Platform
- ✅ Static web app, GitHub Pages deployment
- ⬜ Desktop application with [Tauri](https://tauri.app/)
- ⬜ Real-time collaboration
- ⬜ Cloud project storage
